# Sales Performance Dashboard

## About the Project

The Sales Performance Dashboard is an interactive Excel-based data
analytics project designed to analyze sales performance and generate
useful business insights.

The dashboard presents important sales metrics through interactive
charts, Pivot Tables, filters, and visualizations.

## Objectives

- Analyze overall sales performance
- Track revenue and profit
- Identify top-performing products
- Analyze sales trends
- Compare business performance
- Generate meaningful business insights

## Key Features

- Interactive Sales Dashboard
- KPI Analysis
- Pivot Tables
- Interactive Filters/Slicers
- Charts and Visualizations
- Sales and Revenue Analysis
- Product Performance Analysis
- Profit Analysis
- Business Insights

## Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Analysis
- Data Visualization
